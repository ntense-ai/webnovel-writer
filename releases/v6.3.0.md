# v6.3.0 - English-only author workflows and portable host skills

## Release Scope

This fork release covers the English-first changes after upstream `v6.2.1`,
including the preceding `ntense` localization commits and the English-only schema
conversion. It is intended for new book projects, not an automatic upgrade of
older books.

## Changes for Authors

- New books use English directories, filenames, templates, prompts, reports,
  dashboard labels, schema identifiers, and reference-table metadata.
- All 739 reference rows have English writing guidance, examples and retrieval
  vocabulary. English genre aliases cover all 56 taxonomy entries.
- English prose uses word counts. Unicode story text and names remain supported;
  the project's filenames and structural headings follow English conventions.
- Codex and Antigravity can install project-local portable skills using
  `integrations/install.py`. Claude Code remains supported.
- The Antigravity adapter design credits
  [ezhomelabs/antigravity-webnovel-writer](https://github.com/ezhomelabs/antigravity-webnovel-writer/).

## Do Existing Projects Need Changes?

**This is a breaking, new-project-only fork release.** Localized identifiers,
filename aliases, and the legacy search-vocabulary index were removed. There is
no migration tool or promise of old-book compatibility. Keep existing books on
an appropriate earlier version rather than opening them here expecting conversion.
No existing user books are renamed or translated as part of this source update.

## For Maintainers

- English-only source and filename checks cover the tracked working tree.
- CSV schemas, genre routing, template paths, extraction, summaries, state,
  database projections, dashboard views, and tests now use the same identifiers.
- Test setup isolates current-book pointers and registries from the user's home.
- Portable skills do not install Claude lifecycle hooks or invent host APIs.
  Required independent review still needs actual host subagents; otherwise the
  gated workflow stops. Native host/model writing quality remains unverified.

## Verification

- Full configured Python suite, retaining the 90% coverage gate.
- CSV, plugin-package, and release-note validation; all fast behavior evaluations.
- Dashboard build and Node tests; isolated portable skill installs and fresh-book
  initialization with Unicode story data.
- See [English-only project guidance](../docs/english-compatibility.md) and
  [host adapter boundaries](../integrations/README.md).
