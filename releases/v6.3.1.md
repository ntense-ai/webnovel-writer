# v6.3.1 - Unicode-aware keyword retrieval

## Release Scope

This fork patch covers changes after `v6.3.0` for multilingual BM25 indexing and
search. It does not change story schemas or the English-only project convention.

## Changes for Authors

Keyword retrieval now retains Unicode letters, combining marks and numbers.
Normalization handles case and canonically equivalent accented spellings.
Unspaced CJK, kana and Hangul runs use character and adjacent-bigram tokens.
Previously, Cyrillic, Arabic, kana and Hangul text could produce no searchable
terms, while accented words could be truncated.

This is lexical retrieval, not universal linguistic segmentation, stemming,
translation or cross-language search. Character-based matching can return noisy
partial matches. Semantic retrieval still depends on the configured embedding
and reranking models and has not been validated for every language.

## Do Existing Projects Need Changes?

Stop older running instances before upgrading. On the next adapter startup, a
missing or changed tokenizer-version marker causes a transactional rebuild of
BM25 postings and document lengths from stored chunk text. Existing prose,
embeddings and vector metadata are preserved, without remote API calls.
A large book may take longer on this first startup. Failed rebuilds roll back
the derived index and version marker together. Reopening an up-to-date index
skips the rebuild. The prior English-only schema requirements still apply.

## For Maintainers

The tokenizer version includes the Unicode database version. Change its revision
when tokenization rules change. The stored version and derived postings must be
committed in one write transaction. This patch does not claim multilingual
parity for graph-entity alias extraction or language-specific writing analysis.

## Verification

Real SQLite index/search tests cover English, accented Latin, Cyrillic, Arabic,
Indic text, kana, Hangul and CJK, plus normalization and migration integrity.
The full configured suite retains the 90% coverage gate.
